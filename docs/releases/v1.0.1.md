Folia 音乐站 v1.0.1，修复公开歌单可用性和酷我标准音频播放问题。

- **歌单预检查**：展示公开歌单、推荐和专辑前，检查首批曲目。暂时读不了的条目和已确认没有可用曲目的条目不再展示，检查结果缓存后可在打开详情时复用。
- **过滤受限歌曲**：搜索、榜单和公开歌单过滤平台明确标记不可播、会员或仅试听的曲目；保留原始音源身份和正确分页。
- **修复酷我 AAC 播放**：平台返回 AAC 或 M4A 标准音频时不再错误地按“非 MP3”拒绝播放，保留正确格式及音频类型，无需转码。
- 内置网易云、QQ 音乐、酷狗、酷我、咪咕五个公开音源，原有云账号登录、本地音乐和播放器功能继续保留。

**会员及付费音乐不支持。本项目不是破解版，不解锁或绕过会员权限。** 预检查不下载音频，仅检查首批元数据；未知权限和后续页面会保留。临时请求失败会短暂缓存后允许重试，仍无法保证每首歌在实际播放时都可用。

提供 macOS Apple Silicon / Intel，以及 Windows x64 安装版和便携版。包未做 Apple 公证或 Windows 商业代码签名，下载后可使用 `SHA256SUMS.txt` 核对完整性。

基于 [chthollyphile/folia-major](https://github.com/chthollyphile/folia-major) 的 `main` 分支历史版本 v0.7.27（`4a545c96229664c0e07d4fb04971264e8d75fdd2`）；对应完整修改源码随本 Tag 提供，遵循 AGPL-3.0。
