Folia 音乐站 v1.0.2，修复歌单里出现大量点开就报错的歌曲。

- **按真实音频流过滤**：获取公开歌单、推荐、专辑、榜单和搜索结果时，用各音源自己的解析接口取真实播放地址，并只读取首字节确认是音频。**只展示确认能播的歌曲；整张歌单抽样后没有一首可播就隐藏歌单。** 不再只依赖平台元数据里的「可播」标记——该标记会把需要会员或已下架的歌曲也标成可播。
- **修复搜索与榜单误路由**：内置音源的搜索和榜单结果此前被误当作歌单曲目送去歌单适配器，现已走回正确接口。
- **音源故障降级**：限流、超时或第三方解析服务不可用时，暂时无法确认的条目不展示，但只缓存 30 秒，刷新会重试；单个音源连续失败会短暂熔断，避免一边过滤一边把平台打挂。验证结果带缓存，探测本身不下载整首歌。
- **已知限制**：QQ 音乐的第三方解析服务目前返回「禁止批量下载，请规范使用」或超时，该音源内容会暂时不显示；酷狗在限流时需等待冷却。服务恢复后刷新会自动恢复。**会员及付费音乐不支持，本项目不是破解版，不解锁或绕过会员权限。** 平台状态随时变化，仍不保证每首歌实时可播；已在播放队列中的旧歌曲不受浏览层过滤影响。

提供 macOS Apple Silicon / Intel，以及 Windows x64 安装版和便携版。包未做 Apple 公证或 Windows 商业代码签名，下载后可使用 `SHA256SUMS.txt` 核对完整性。
